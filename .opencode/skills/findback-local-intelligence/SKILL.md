# FindBack local intelligence

Keep narrow local tools separate from optional BYOK cloud AI Chat.

| Concern | Owner / contract |
| --- | --- |
| Extraction | Needle structured task schemas and validators; fail closed |
| Semantic matching | Bundled USE default; optional Needle path, validated vectors |
| Lifecycle | Shared application service, verified downloads/resume/remove, native-settlement leases |
| Cloud | Separate provider/vault/history owners; not a local fallback |
| Retired installs | Frozen cleanup-only identities, never download offers or runtime candidates |

Before editing, trace real callers; test imports are not shipping reachability.
Preserve exact revision/hash/size/file pins and required legal snapshots.
Keep cancelled/reset native work excluded until settlement. Keep account fencing,
consent, structured validation and bounded inputs; never silently send local tool
inputs to cloud. Do not restore retired local assistant/photo engines, arbitrary
model import/evaluation, or a promotion lab to satisfy an old test.

Run focused compiler/lint/behavior tests through `heavy-run`, with resource checks,
capped workers and background completion evidence. Check retained native owners
and strict APK packaging where relevant. A host fixture, desktop benchmark or
static source check is not physical-device acceptance or matching-corpus proof.
Report device and owner-corpus gaps explicitly; do not invent a qualification.
