Beta checkpoint, not a stable release. No automatic tag/GitHub Release or APK.

## Delivered source

Report → Discover → Match → Contact → Recover stays primary. The server scores
eligible category/text/date/location candidates before the80-item cap; existing
local Needle/USE/visual ranking and non-native web baseline remain. Visibility,
moderation and block owners are not replaced.

`design/colorSystem.ts` is the colour-value owner; appearance persistence and
theme runtime stay separate. Fresh default is Blue. Android12+ optional
System colours are device-local with contrast/fallback/lifecycle guards. Graphite
dark, calm light and true-black AMOLED retain fixed semantic roles. Wide devices
choose rail/bottom locally; phones keep bottom navigation without a prompt.

The same-domain `/api/share/:uuid` renderer and SPA use one six-field sanitized
projection. Legacy `/r/:uuid` links remain. No raw prose, contact, exact location,
photos or private action is exposed. Revocation/moderation/deletion apply on fresh
requests; historical third-party crawler caches cannot be promised erasable.

The unused course-era Node API and reference containers are retired after non-use
and test-contract inventory. Optional BYOK AI Chat stays secondary; no retired
local-generative runtime returns. Canonical R4 messaging/recovery owners remain.
