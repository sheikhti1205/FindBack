# Course-era material

FindBack began in 2026 as a university course project. This folder keeps that
material for provenance: what was asked, what was planned, and how the project was
evaluated at the time.

**None of this is the current product specification, and none of it is acceptance
evidence.** Current status lives in the [README](../../README.md),
[docs/history/VERSION_HISTORY.md](../history/VERSION_HISTORY.md) and the
[functional freeze record](../releases/BETA_FUNCTIONAL_FREEZE_2026-10-30.md).

## Still at their original paths

The completion gate (`scripts/completion-gate.mjs`) requires these files at fixed
paths and treats them as current documentation, so they were not moved. They are
course-era acceptance material, kept in sync with the gate:

- [DEFERRED_DECISIONS.md](../../DEFERRED_DECISIONS.md)
- [docs/REQUIREMENTS_MATRIX.md](../REQUIREMENTS_MATRIX.md)
- [docs/FINAL_ACCEPTANCE_REPORT.md](../FINAL_ACCEPTANCE_REPORT.md)
- [docs/DEMO_CHECKLIST.md](../DEMO_CHECKLIST.md)
- [docs/COMPLETION_AUDIT.md](../COMPLETION_AUDIT.md)

Read them as history. A "READY" line in a course-era report means the course
deliverable was closed at that time; it is not a statement that the current beta is
public-ready.
