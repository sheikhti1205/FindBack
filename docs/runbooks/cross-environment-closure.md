Actions, GitHub Release, and source-map upload. No lane mints its own name.

`VITE_SENTRY_TRACES_SAMPLE_RATE`, `SENTRY_AUTH_TOKEN`, `SENTRY_ORG`,

```sh

node scripts/sentry-cross-lane-proof.mjs --asset <dist-dir>
node scripts/check-signeddev-config.mjs               # lane wiring
```

The proof prints release `findback-mobile@<version>+<short12>` (exactly-12),
the closed dist, the DSN **hostname only**, source-map count, and upload
readiness — never a token or DSN key.

Synthetic-error acceptance (one run per project `canvas-of-nomads/findback_capacitor`):

1. Device: one `VITE_MONITORING_SELFTEST=true` run fires `sendMonitoringTestSignal`
   (handled error + warning + breadcrumb); normal startup never auto-fires it.
2. Confirm the event reaches the correct Sentry project.
3. Confirm the event's release says the exact `<version>+<short12>` and dist.
4. Confirm the stack trace resolves against the uploaded maps (not minified).
5. Confirm debug/signeddev/release do not merge under the wrong release/dist.

Sentry stays `READY_FOR_RUNTIME_PROOF` until step 2–4 are observed.
