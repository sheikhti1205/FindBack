# FindBack v0.9.0-beta.1

Signed Android **pre-release**. Not a production/Latest release. See
`release-manifest.json` for versionCode, git SHA, and per-artifact checksums.

This beta is a targeted finishing wave: a consumer-ready Assistant screen,
a neutral structural palette, and real dependency-security closure. It does
**not** redesign the feed, AI/guided/chat logic, or any stored data.

## Assistant / Help landing

- First use now shows a compact, consumer-facing landing instead of a synthetic
  greeting bubble dropped into the transcript.
- The landing presents: a short welcome, **Popular questions**, **Quick
  actions** (report lost / report found / search), a concise **How the
  assistant works** explainer, and a collapsed **Privacy & AI details**
  disclosure that expands in one tap.
- Every existing capability is preserved: free / connected / on-device / cloud /
  auto modes, the model picker, provider credentials, per-account history,
  retry, stop/cancel, streaming, image attachments, guided lost/found/search
  flows, staged navigation, FAQ fallback, provenance labels and privacy
  disclosure.
- The transcript's "New response" control can no longer appear on an empty or
  brand-new conversation; it still works when you scroll up in a real chat.

## Neutral structural palette

- Page, cards, sheets, search, headers, navigation and generic containers now
  use a neutral structural palette in every theme (light, dark, system-dark,
  AMOLED). No green/blue/cream/sage/ivory tint remains on those surfaces.
- The Found badge is neutral; status is carried by its icon and label, never by
  colour alone.
- All appearance settings remain fully functional: System / Light / Dark /
  AMOLED, text size, reduced motion, high-quality-photo, live apply, and saved
  preferences with migrations.

## Accent

- All seven accent options are kept: emerald, blue, violet, rose, amber, teal
  and **mono**.
- The default accent is now **mono** for new installs only. Any saved accent
  preference is preserved and still applied.

## Security

- Fresh dependency audit with two high-severity advisories closed:
  - `@graphql-tools/utils` prototype pollution (CVE-2026-104852 /
    GHSA-7mx3-vvmw-hjmv) via `graphql-yoga` — pinned to `12.0.1`.
  - `sharp` (CVE-2026-96889 / GHSA-wq5f-xc86-pv6w) — bumped to `0.35.5`.
- `npm audit` and `npm audit --omit=dev` both report **0 vulnerabilities**.
- New deterministic guards run in CI and release: a security-baseline tripwire,
  high-severity `npm audit` gates, and an API regression proving the installed
  `mergeDeep` ignores `__proto__` / `constructor.prototype` payloads.

## No data reset

This update does **not** delete or reset user data. Auth users, profiles,
reports, comments, reactions, matches, notifications, storage objects, chats,
credentials and profile data are left untouched. Installing over a previous
beta upgrades in place.

## Install

Download the APK that matches your device ABI (`arm64-v8a`, `armeabi-v7a`, or
`x86_64`), or the universal APK if unsure. The `.aab` is for Play-style
distribution only and is not directly installable.

## Verification

- `release-manifest.json` carries the versionCode, git SHA and checksums.
- `SHA256SUMS.txt` carries per-artifact SHA-256 sums; verify with
  `sha256sum -c SHA256SUMS.txt`.
- The web bundle is built with the FindBack server URL and publishable key
  baked in and is checked post-build by `scripts/check-release-config.mjs`.

Physical-device acceptance remains an owner-run step.
