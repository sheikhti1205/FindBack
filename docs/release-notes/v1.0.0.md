# FindBack v1.0.0

First **stable** release. Signed per-ABI APKs + universal APK + AAB.
See `release-manifest.json` for versionCode, git SHA, and per-artifact checksums.

This release promotes the v0.9.0-beta.1 line plus everything closed after it:

- Consumer Assistant/Help screen: role-qualified Automatic routing (Needle is
  never used for text chat), native Android media intake with
  Preparing/Ready/Failed rows and Retry/Remove, modern + legacy Motion Photo
  support, HEIC/HEIF/AVIF normalization, adaptive streaming paint, one
  consolidated status region, free-first Recommended model ordering, and a
  concise Privacy & AI sheet with a Full-details route.
- Response identity: the coordinator owns outward attempt identity and the
  controller accumulates attempt-locally, so a retry can never blend a failed
  attempt's text into the successful answer; partial text is in-flight
  streaming only and a synchronous send mutex makes a double tap one send.
- Neutral structural palette in every theme; all seven accents kept.
- Full release gate green: mobile + API suites, typecheck, lint, secret scan,
  AI release gate, APK scan (DEX/assets/JNI/16 KiB), packaged Supabase/Sentry
  verification, sha256 checksums.

Device/live-provider rows that need a physical phone remain tracked with
written owner waivers in the completion ledger; nothing open blocks install.

## Versioning from here

Releases follow SemVer, cut from accumulated commits — commits pile up,
release numbers jump only when a release is cut:

- cheap, low-risk fixes bump the patch (`1.0.0` → `1.0.1`);
- impactful changes bump the minor (`1.1.0`);
- breaking or generational work bumps the major (`2.0.0`).

`versionCode` stays fully automatic (`100000` + commit count), so every
commit is install-ordered with no hand-bumping. Tag == `v` + mobile version,
exactly.
