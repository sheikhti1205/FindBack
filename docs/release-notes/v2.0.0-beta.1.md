# FindBack v2.0.0-beta.1

Signed Android **pre-release**. Not a production/Latest release. See
`release-manifest.json` for versionCode, git SHA, and per-artifact checksums.

This beta is the second-generation wave: web/Android sign-in parity, a live
backend (database + Edge Functions) brought into byte-level parity with the
repository, an in-app GIF picker, a keyless map stack, and closed cross-lane
observability. It does **not** reset any stored data.

## Sign-in — web + Android parity

- **Android** keeps the platform flow: Credential Manager → Google ID token +
  nonce → `signInWithIdToken`, with no web client secret on device.
- **Web** adds `signInWithOAuth({ provider: "google" })`. The OAuth redirect
  lands on an allowlisted `/auth/callback` (and `/recovery`) route; the code is
  exchanged exactly once, the URL is stripped before app modules load, and the
  same profile resolver and Complete Profile step run afterward.
- PKCE is pinned (`flowType: "pkce"`, `detectSessionInUrl: false`). No
  `GOOGLE_WEB_CLIENT_SECRET` is shipped to the client.

## Live backend parity

- Database: all pending migrations applied to the live project; live head now
  matches `BACKEND_SCHEMA_VERSION`. A real signature-drift defect in an avatar
  migration was found and fixed, with a new regression guard so a future
  re-declaration cannot silently desync from the client.
- Edge Functions: `ai-help`, `push-dispatch`, `cleanup-comment-media` and
  `reply-comment` deployed and proven byte-identical to the repository, with
  live authentication guards returning `401` for missing credentials.

## GIF picker

- The comment composer can attach a GIF from KLIPY, with 44px touch targets and
  a search field that meets the same minimum.

## Maps

- MapLibre Native with keyless OpenFreeMap Liberty tiles and Nominatim
  explicit-submit search. No Google Maps or Places dependency; a guard blocks
  their reintroduction.

## Observability

- One Sentry release scheme across lanes (`findback-mobile@<version>+<short12>`)
  with a closed dist map, so events, source maps and symbolication line up.

## No data reset

This update does **not** delete or reset user data. Auth users, profiles,
reports, comments, reactions, matches, notifications, storage objects, chats,
credentials and profile data are left untouched. Installing over a previous
build upgrades in place.

## Install

Download the APK that matches your device ABI (`arm64-v8a`, `armeabi-v7a`, or
`x86_64`), or the universal APK if unsure. The `.aab` is for Play-style
distribution only and is not directly installable.

## Verification

- `release-manifest.json` carries the versionCode, git SHA and per-artifact
  SHA-256 checksums.
- Every split APK and the AAB are verified by `scripts/verify-release-apks.sh`:
  identical pinned signing certificate, app id / versionName / versionCode /
  SDK levels, expected native ABI contents, strict secret scan, and baked
  Supabase + Sentry config.
- The web bundle is built with the FindBack server URL and publishable key baked
  in and is checked post-build by `scripts/check-release-config.mjs`.

Physical-device acceptance remains an owner-run step.
