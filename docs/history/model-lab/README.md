# Historical model-lab records

Archived during M7-P repository simplification. These records describe past
experiments, source states, failures and deferred gates, **not current product
capabilities or an executable acceptance queue**. Historical paths/commands may
refer to deleted code; consult the relevant Git revision to reconstruct them.
No failed or deferred device/model gate becomes passed through archival.

The legal snapshot at `evidence/model-license-packet.json` is preserved byte for
byte, including retired artifacts and upstream text/attribution. Its integrity
is still checked by `scripts/check-model-notices.mjs`; it is not a runtime model
catalogue. Active local tools are Needle extraction/embeddings and USE semantic
matching. Optional BYOK cloud AI Chat has separate provider/key/history owners.
